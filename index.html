1.1.컴퓨팅 시스템의 구성과 동작

Apps Script 주소를 입력하고 저장하세요. JSON 파일은 사용하지 않아요. 학생 전체에 적용하려면 주소가 반영된 HTML을 내려받아 GitHub의 기존 수업 HTML과 교체해 주세요.

이 화면은 비밀번호로 보호된 관리자 페이지가 아니라 공개 연결 설정 도구예요. HTML에는 공개 웹앱 주소만 들어가며 비밀번호나 API 키는 넣지 않아요. 설정 저장만으로 GitHub 파일이나 다른 학생의 브라우저 설정이 바뀌지는 않아요.
학생 화면으로

주소를 변경할 때

  1. 새 /exec 주소를 입력해요.
  2. 주소를 저장하고 HTML을 내려받아요.
  3. GitHub의 기존 수업 HTML을 같은 이름의 새 HTML로 교체해요.
  4. GitHub Pages 배포 완료 후 학생이 페이지를 새로고침해요.

기존 배포를 ‘새 버전’으로 업데이트하면 일반적으로 주소가 유지되어 설정을 바꿀 필요가 없어요. 새 배포로 주소가 달라졌을 때 수정하면 돼요. 주소 저장은 이 기기·브라우저에만 적용돼요. 학생 전체 적용에는 HTML 교체가 필요해요.

2. 하드웨어를 우리 몸에 비유하면?

몸 주변의 버튼을 누르면 해당 역할의 사진·비유·사례가 나타나요.

역할을 이해하기 위한 단순화된 모형
비유의 한계: 뇌는 판단과 기억을 함께 하고, 손은 만져서 입력받거나 표현하는 데 모두 쓰여요. 통신도 한 기관이 아니라 상대와 정보를 주고받는 활동에 비유한 것이에요. 사람의 기억은 RAM처럼 전원이 꺼져서 사라지는 것이 아니에요.
RAM·SSD·HDD는 어떻게 다를까요?
RAM(주기억 장치): 실행 중인 프로그램과 데이터를 임시로 기억해요. 전원이 꺼지면 내용이 사라져요. ‘지금 머릿속에 떠올려 작업하는 내용’에 비유할 수 있어요.
SSD·HDD(보조 기억 장치): 프로그램과 파일을 장기간 저장해요. 전원이 꺼져도 남아요. 신체 기관보다는 ‘공책에 기록해 보관하기’에 비유하면 더 쉬워요.

SSD와 HDD 비교: SSD는 반도체에 저장하고 움직이는 부품이 없어요. HDD는 회전하는 자기 디스크와 읽기·쓰기 헤드를 이용해요. 둘 다 전원이 꺼져도 데이터를 보관하는 보조 기억 장치예요. 일반적으로 SSD가 접근 속도가 빠르고, HDD는 같은 비용으로 큰 용량을 마련하는 데 유리해요.
여기서는 주기억 장치 중 RAM을 중심으로 배워요.

사진 카드 분류 실험실

① 카드를 눌러 확대 → ② 닫고 역할 선택 → ③ 확인하기
드래그하지 않아도 사용할 수 있어요. 카드를 다시 선택하면 분류를 바꿀 수 있어요.

와이파이는 통신 기술, 무선 랜 어댑터는 통신 장치예요. 터치스크린은 터치를 감지하는 입력과 화면을 보여 주는 출력을 함께 담당해요.

3. 키오스크 주문은 어떻게 처리될까요?

메뉴를 입력하고 주문을 처리하며 입력·처리·출력·기억·통신을 연결해 보세요.

운영체제가 장치와 자원을 관리하고, 주문 앱은 주문 작업을 수행해요. 실제로는 여러 과정이 반복·병렬로 일어나지만, 이 모형에서는 차례대로 살펴봐요.
